How to save a GTA 6 clip after it happens on PS5

If you just landed a jump and want the replay, press the DualSense Create button and choose Save Recent Gameplay. Pick a duration long enough to include the approach. The PS5 keeps recent gameplay available for capture, so you can do this after the landing.

Which capture option fits the moment?

Already happened
Save Recent Gameplay saves an earlier stretch. Sony lists durations from 15 seconds up to one hour.
Happening now
Take Screenshot saves the current frame. Use it for a skyline or a settings screen you want to look up later.
About to happen
Start New Recording before setting off. Open Create again at the end and select Stop Recording.

Example: keep the approach as well as the landing

Suppose the landing was ten seconds ago and the run-up took another twenty. A 15-second clip would show only the last five seconds of the approach. Choose an available duration longer than thirty seconds, then check the start and end of the saved video.

Where did the clip go?

Open Create and select the recent thumbnail. Play the clip and check that the moment is present before starting another attempt. If a section is missing, Sony notes that some scenes block capture. If Create behaves differently on your controller, check your customized button settings.
