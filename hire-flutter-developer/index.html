A simple process

Scope. Build. Ship.

  1. Share the goal. Tell me who the app is for, what it should help them do, and whether you already have designs or code.
  2. Define the first scope. We narrow the work into clear screens, features, integrations and delivery expectations.
  3. Build and review. The app is implemented in practical milestones so decisions can be checked before release.
  4. Prepare to launch. We finish the agreed release work for iOS, Android or both.
Before you email

Useful details to include.

You do not need a formal specification. A short message is enough to start.

  • What the app should help users do
  • Whether you need iOS, Android or both
  • Any designs, codebase, API or Firebase project that already exists
  • Your preferred timeline and budget range, if known
