Questions

Start with one small routine.

Can a habit repeat only on selected days?

Yes. You can choose specific days, a start date and a frequency that matches the routine.

Do I need to create an account?

No. Habit data is stored locally and the app does not require a sign-in.

Can I move my habits to a new device?

Yes. Export your data to a file and import that file on the other device.
