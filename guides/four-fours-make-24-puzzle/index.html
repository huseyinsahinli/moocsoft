Four 4s Puzzle: Make 24 and Solve 11 More Targets

Make 24 with exactly four 4s: (4 × 4) + 4 + 4 = 24. This solution uses multiplication first, then adds the remaining two 4s. Keep the rule fixed—four copies of the digit 4, each used once—and check both the arithmetic and the digit count before accepting an answer.

The useful takeaway

Write the allowed operations before solving. The practice below uses addition, subtraction, multiplication, division and parentheses; each expression contains exactly four 4s. It does not use concatenation, decimals, factorials, exponents or other digits.

Start with the 24 solution and write the rules

The target is 24. A valid answer is (4 × 4) + 4 + 4 = 24: multiply the first pair to get 16, then add 4 and 4. Count the digits in the written expression—there are exactly four. Parentheses make the grouping visible, even though ordinary order of operations also evaluates the multiplication before addition.

For this page, use exactly four 4s and only +, −, ×, ÷ and parentheses. Use standard order of operations. Do not join digits into 44 or introduce a decimal point, factorial, exponent or another number. Puzzle collections sometimes permit different rules; an answer is valid only under the rule set being used.

These are invented educational expressions, not solutions copied from a numbered game. First write the allowed symbols on paper, then test the expression. If you get a different result, check the grouping and operation order before deciding the puzzle is impossible.

Try a target before opening the answer list

Using the same rules, make 0, 1, 2, 3, 5, 6, 8, 9, 12, 15 and 16. Try one target at a time. For each answer, check that the expression has four digit-4 tokens and that the operations produce the target.

When you are ready, compare your expressions with one valid set of answers. Some targets can have more than one valid expression; the list gives one per target.

Every row uses the same four allowed operations and ordinary precedence. For example, (4 × 4 + 4) ÷ 4 = 5 because 16 + 4 = 20 and 20 ÷ 4 = 5. The parentheses keep the numerator together.

Check the answer without guessing

Use this four-step check for each line:

  1. Count: exactly four digit-4 tokens appear.
  2. Scan: no unallowed symbol or extra number appears.
  3. Group: parentheses are balanced and show the intended order.
  4. Calculate: evaluate multiplication and division before addition and subtraction, moving left to right within the same precedence level.

For 24, the grouped expression is (4 × 4) + 4 + 4 = 16 + 4 + 4 = 24. A common mistake is to calculate an unparenthesized string strictly left to right even when multiplication appears before addition. Another is to use a fifth 4 while trying to repair an expression. Count the symbols again after making any change.

If a different puzzle source allows concatenation, factorials or decimal points, treat those as separate rules. Do not silently borrow them for this worksheet: adding an operation changes which answers are permitted.

Try changing the target, not the rule halfway through

Choose a new whole-number target and see whether you can make it with four 4s under the stated rules. Write a proposed expression first, then check it with the same count and precedence steps. If you cannot find one, label it “not solved yet”; a short search is not proof that no expression exists.

Common questions

How do you make 24 with four 4s?

One solution is (4 × 4) + 4 + 4 = 24. It uses exactly four 4s and standard arithmetic operations.

Can I use 44 in the four-fours puzzle?

Not under this guide’s rules. Each 4 must remain a separate digit; concatenation, decimals, factorials and exponents are excluded. Other versions may set different rules.

What order of operations should I use?

Evaluate parentheses first, then multiplication and division from left to right, then addition and subtraction from left to right.
