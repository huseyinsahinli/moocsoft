02

Completing a set starts the countdown. Pause it, adjust it, skip it or end it immediately.

03

04

Portable plans

Send the week, not your history.

Premium can export a complete seven-day plan as a Did You Lift link or a readable JSON file. Completed workouts, actual weights and active timers never leave your phone.

Open Share on the week screen

Choose a link for convenience or a JSON file for the most reliable transfer.

Send it with any app

The file is ordinary JSON. No Moocsoft account, cloud upload or hidden server copy is created.

The receiver previews it

Did You Lift shows the number of exercises and sets before anything is changed.

Import replaces the planned week

Existing completion history remains. Any active workout ends because the plan has changed.
